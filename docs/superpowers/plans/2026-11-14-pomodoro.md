# Помодоро — план сборки

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать личное приложение помодоро на Tauri для Windows и macOS: трей или меню-бар, панель, лента дня, теги и статистика.

**Architecture:** Правила таймера — чистые функции TypeScript от настенных часов. React только рисует `derive`. Закрытие окна прячет его, процесс и сессия живут дальше. Состояние целиком пишется в один JSON в каталоге приложения. Rust отвечает за трей, кольцо на иконке, уведомления и автозапуск.

**Tech Stack:** Tauri 2, React, TypeScript, Vite, Vitest, Testing Library. Плагины: `notification`, `autostart`, `single-instance`. Хранение: `pomodoro.json` версии 1, без базы и без сети.

**Spec:** `docs/superpowers/specs/2026-11-14-pomodoro-design.md`

## Global Constraints

- Продукт один на Windows и macOS. Имя окна и трея: `Помодоро`. Идентификатор: `com.pomodoro.app`.
- Интерфейс по-русски. Строки ниже копировать буквально.
- Таймер от настенных часов. `focusEndsAt = startedAt + plannedMinutes`, пауза переносит `focusEndsAt`, не `startedAt`.
- Выход из процесса не стирает и не ставит на паузу открытую сессию. Следующий запуск вызывает `settle`.
- Закрытие окна прячет его. Сессия не останавливается.
- Добавочные минуты: `N = min(180, floor(elapsedMs / 60000) + 1)`. На 0 мс уже `1`. На 60000 мс уже `2`. Выше 3 часов кнопка остаётся `Добавить 180 мин`, часы стоят на `+3:00:00`.
- «Добавить N мин» пишет `plannedMinutes + N` и начинает перерыв. «Перерыв» пишет ровно `plannedMinutes` и начинает перерыв.
- «Сдаться» только до нуля. Сессия не пишется, перерыв не начинается.
- Короткий перерыв 5, длинный 20, длинный после каждых 4 записанных сессий. После перерыва фокус сам не стартует.
- Звук и уведомление один раз на переход в добавочное время и один раз на конец перерыва. Пока `N` растёт, новых сигналов нет. Фоновых звуков нет.
- Текст фокуса: `Время вышло. Можно ещё поработать или уйти в перерыв.` Текст перерыва: `Перерыв закончился.`
- Клик по уведомлению открывает панель.
- Меню трея: `Пауза` или `Продолжить`, `Открыть`, `Выйти`. Продления и перерыва в меню нет.
- Меню-бар Mac: фокус `24:12`, добавочное `+3:12`, перерыв `перерыв 5:00`, простой без цифр. Подсказка Windows: та же строка, затем ` · ` и имя тега. Для перерыва подсказка `перерыв 5:00 · Перерыв`.
- Большие цифры панели: `25:00`, `+03:12`, подпись `было 25:00`.
- Теги при первом запуске: `Работа` `#E07A4C`, `Учёба` `#E0A24C`, `Своё` `#D4C06A`, у каждого 25 минут, выбран `Работа`. Идентификаторы: `tag-work`, `tag-study`, `tag-own`.
- Длины фокуса только из списка: 5, 10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60, 75, 90, 120, 150, 180. Смена длины до старта запоминается в теге.
- Убранный тег исчезает из выбора. Его прошлые сессии на ленте остаются. Переименование тега меняет имя на ленте.
- Лента: день и неделя. Неделя с понедельника, границы дня в местной зоне. Статистика: день, неделя, месяц, год. Пустой день: `В этот день сессий не было.`
- Сессию можно удалить. Добавить сессию задним числом нельзя.
- Блок сессии идёт от `startedAt` до `startedAt + recordedMinutes * 60000`. Подпись длины — записанные минуты, не настенный промежуток.
- Горка помидоров не реагирует на мышь и наклон. Масштаб: `clamp(recordedMinutes / 25, 0.8, 2)`.
- Настройки спрятаны в окне дня, на панели их нет. Звук, уведомления и автозапуск включены. Тема: `system`, `light`, `dark`.
- Пробел ставит паузу и снимает её. Из простоя пробел сессию не начинает.
- Подсказка Windows в настройках: `Windows прячет новую иконку. Перетащите её из стрелочки к часам, чтобы время было видно.`

## Review Focus

- Сон или закрытое приложение пересекает ноль: при запуске фаза уже добавочное время, `N` равен прошедшим минутам, сигнал фокуса вооружается один раз и вторым тиком не повторяется.
- Пауза на добавочном времени замораживает `N` и цифры. Стена, прошедшая во время паузы, в `N` не входит. После продолжения рост идёт от замороженного значения.
- «Перерыв» после добавочного времени пишет только план. «Добавить N мин» пишет план плюс `N`. Обе кнопки начинают перерыв, а не новый фокус.
- Закрытие окна и выход из процесса не стирают `focusEndsAt` и не переводят сессию в паузу.
- Четвёртая записанная сессия открывает перерыв 20 минут, пятая — 5 минут. «Сдаться» до нуля не пишет сессию и не двигает цикл.
